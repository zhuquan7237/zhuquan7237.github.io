和其他社区桌面版的区别

官方 DeepSeek Harness 只有命令行和本地网页。社区里一下子出现了很多同名 Electron 桌面端。这个项目是基于官方引擎的薄壳，不整仓拷贝官方源码。 搜「DeepSeek Harness Desktop」时，星标高的仓库会排在前面。 这个项目不跟他们比星标，只把差别写清楚，方便你选对安装包。

去下载 0.1.12 打开搜索名仓库

一句话

这个项目

薄薄一层 Electron 壳，不整仓拷贝官方源码。启动时从 npm 安装官方 @deepseek-ai/dsh。Windows / Linux / macOS（含 Intel）都有包。 默认皮肤打进安装包。旧版 API Key 会尽量接过来。

整仓拷贝官方源码的桌面版

把 deepseek-ai/deepseek-harness 整份放进自己的仓库，再加 Electron。 GitHub 上会显示成很大的 TypeScript 项目，搜索和星标都更显眼。 引擎更新要等作者再同步那份拷贝。
