PROJECT BOUNDARY

不是另一个 Harness fork。

DeepSeek Harness Desktop 是朱泉做的社区 Electron 桌面端。它负责安装包、窗口和本地启动； Harness 引擎始终来自 npm 的 @deepseek-ai/dsh，不整仓拷贝官方 monorepo。

WHAT IT IS

这个项目只做这些事

把本地 Web UI 放进窗口

提供桌面图标、快捷方式、工作区和中文菜单。它不是另做一个聊天网页。

把启动环境准备好

首次运行准备 Node，从 npm 安装引擎，再启动官方 Harness 服务。

发布跨平台安装包

0.1.12 提供 Windows、Linux tar.gz / deb、macOS arm64 / x64。

清楚保留上游边界

Harness 归官方项目；默认皮肤也有自己的 CC BY-NC-SA 4.0 署名链。
