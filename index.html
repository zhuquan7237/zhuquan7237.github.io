DeepSeek Desktop

原生窗口里的 Codex 式使用界面。引擎始终是官方 DeepSeek Harness （@deepseek-ai/dsh），从 npm 独立更新，所以 harness 发新版不必重做这个桌面软件。 安装包覆盖 Windows / macOS / Linux，x64 与 arm64。

下载安装包 浏览器预览 番茄钟

Thin shell

桌面程序只负责窗口、安装包、工作区选择，以及把官方 dsh web 嵌进去。

Full harness

工具、插件、Plan/Agent、设置、Web UI 全部来自官方 harness，能力随 dsh 升级自动跟上。

Independent updates

启动时检查 npm 上的 @deepseek-ai/dsh@latest。也可指向本地已构建的 harness 源码目录。
