怎么用

1

下载并打开

Windows 用安装包，Linux 解压 tar.gz 后运行 ./DeepSeek，macOS 拖到应用程序。

2

等第一次联网

大约 1–3 分钟。软件会自己准备 Node，从 npm 安装官方引擎。默认皮肤已打进安装包。中文系统或中国时区默认走国内镜像。

3

填写 API Key

在官方界面里粘贴 DeepSeek API Key。之后用菜单「Harness → 检查更新」升级引擎即可。

主要功能

Desktop

把官方 DeepSeek Harness 的本地 Web UI 带到原生窗口。自动准备 Node、启动 dsh、记住工作区。Windows / Linux / macOS（含 Intel Mac）都有安装包。

官方引擎，不整仓拷贝

工具、插件、Plan/Agent、Web UI 都来自 npm 上的 @deepseek-ai/dsh。官方发新版时，菜单「检查 Harness 更新」即可，不必等别人再同步一份 fork。

皮肤中心

默认「深海女仆工坊」已打进安装包，离线也能用，不用再从 GitHub 拉。右上角鲸鱼按钮可换皮，也可从文件夹或 GitHub 地址导入。

国内网络与旧配置

中文系统或中国时区默认走国内 npm 镜像。从旧桌面版升级时，会尽量把 API 密钥和设置接过来。

为什么不是再 clone 一份官方仓库

给普通人用

没有终端、没有 Node 也能打开。有桌面图标、开始菜单和工作区默认目录。

引擎保持官方

工具、插件、Plan/Agent、Web UI 都来自 @deepseek-ai/dsh。这不是 fork，也不是换皮聊天框。

更新很轻

Harness 发新版时，桌面软件不用重做。菜单里检查更新，只下载新的 dsh 包。

常见问题

搜 DeepSeek Harness Desktop 怎么找到这个项目？

GitHub 搜索名是 zhuquan7237/deepseek-harness-desktop。 安装包和源码在 dsh.zhuquan.xyz / GitHub。 和同名热门仓库的差别见 和其他桌面版。

这是官方软件吗？

引擎是官方 DeepSeek Harness。桌面安装包由 朱泉 做，方便下载和双击，不是 DeepSeek 公司发的商店应用。

要不要 git clone？

不用。请直接下载 0.1.13 安装包。不要用 0.1.0–0.1.12。装好后菜单里可以检查桌面版更新。

macOS 说文件已损坏？

不是下坏了，也不是缺许可证。macOS 隔离了网上下来的未公证软件。 请用 0.1.13，把 App 拖到「应用程序」后，在终端运行 xattr -cr /Applications/DeepSeek.app。 逐步说明：macOS 打不开。

检查更新后弹出 dsh exited 1 / cordis.patch.yml？

这是 0.1.10 的问题：皮肤补丁写成了只有注释的文件，官方 dsh 要求顶层必须是 YAML 数组。 请改用 0.1.13。若暂时打不开，把 dsh-home/cordis.patch.yml 改成 [] 或删掉后重启。

更新后 API Key 没了 / 皮肤拉不下来？

0.1.13 会从旧目录把密钥接回来（当前 %AppData%\DeepSeek 或 ~/.config/DeepSeek，以及更早的 深度求索、~/.dsh）。 默认皮肤已打进安装包，不再访问 GitHub。请不要删掉这些配置文件夹。

API Key 在哪拿？

打开 platform.deepseek.com，在官方界面里粘贴即可。

默认皮肤是谁做的？能商用吗？

默认皮肤「深海女仆工坊」来自 Small-tailqwq/dsh-deep-whale， 以 CC BY-NC-SA 4.0 发布，禁止商用。 角色形象一创是上善，二创是 ZipZipPipe，三创是 Small-tailqwq。 可在皮肤列表、菜单「皮肤」或引擎设置里关闭皮肤中心。完整致谢见本页 皮肤一节。
