DeepSeek Harness 桌面版

官方 Harness 很好用，但普通人还是得自己 clone、装 Node、在终端里启动。 我做了一层薄桌面壳：安装包、快捷方式、图标、中文菜单，引擎始终从 npm 拉官方 @deepseek-ai/dsh。 默认皮肤「深海女仆工坊」来自 Small-tailqwq/dsh-deep-whale， CC BY-NC-SA 4.0，禁止商用。署名链：上善 → ZipZipPipe → Small-tailqwq。 画面不是我画的，产品页写了完整致谢。

我想做什么

不是把演示稿停在「能在我电脑上跑」。我想把软件交到没配过开发环境的人手里： 有图标、有快捷方式、第一次打开知道在等什么、坏了能看懂原因。

DeepSeek Desktop 0.1.13 是目前最完整的一次练习：跨平台打包、公开下载、皮肤打进安装包、升级时继承旧版 API 密钥，以及给普通人看的说明。默认皮肤版权见产品页。
