CURRENT PROJECT

DeepSeek Harness Desktop

一个社区 Electron 桌面端：自动准备 Node，从 npm 安装官方 @deepseek-ai/dsh，再把本地 Harness 界面放进独立窗口。 项目不整仓拷贝官方源码，也不代表 DeepSeek Inc.

0.1.19 提供 Windows、Linux（含 arm64）、Apple Silicon 与 Intel Mac 安装包； 修好了零配置 Linux 首次安装（不再依赖 xz，失败可重试）。默认内置「深海女仆工坊」，并尝试迁移旧版 API Key。
