下载 和其他桌面版 macOS 打不开 关于朱泉

macOS Sequoia / Tahoe

提示「已损坏」时这样开

不是许可证没加，也不是你的安全开关没开对。macOS 会给浏览器下载的软件打隔离标记； 我们还没有付费做 Apple 公证，系统就把隔离后的 App 显示成损坏。 VS Code、Obsidian 能双击打开，是因为它们买了开发者账号并提交公证。

现在就做（约 1 分钟）

1

确认芯片和安装包

左上角苹果菜单 → 关于本机。芯片是 Apple M 系列就用 mac-arm64.dmg，Intel 用 mac-x64.dmg。 下完对照 GitHub Release 的文件大小，没下完不要打开。

2

拖到「应用程序」

打开 dmg，把 DeepSeek 拖到右边的 Applications / 应用程序。不要只在安装盘里双击用。

3

终端去掉隔离（最稳）

打开「终端」，整段粘贴回车。不必输入密码。

xattr -cr /Applications/DeepSeek.app
open /Applications/DeepSeek.app

也可以输入 xattr -cr 加一个空格，再把 DeepSeek 图标拖进终端窗口。

4

仍要打开

若还提示无法验证：系统设置 → 隐私与安全性 → 往下滚 →「仍要打开」。 Sequoia 上右键「打开」经常没用。不要关 SIP，也不要执行 spctl --master-disable。

这和「权限」的区别

损坏 / 无法验证

Gatekeeper 隔离。用上面的 xattr。不是缺软件许可证。

打开之后才问的权限

文件与文件夹、网络。能启动后再允许即可。现在打不开，先不用开「完全磁盘访问」。

以后怎样双击无提示

加入 Apple Developer Program（年费），用 Developer ID 签名并公证。安装盘里的脚本去不掉这个要求。

把检查结果发我

若还是打不开，把下面四行的输出发过来（不含任何 API 密钥）：

uname -m
sw_vers
ls -l ~/Downloads/DeepSeek*.dmg /Applications/DeepSeek.app
xattr -l /Applications/DeepSeek.app

xattr 里如果有 com.apple.quarantine，说明还在隔离，把第 3 步再做一次。
